# Train/Test Evaluation Design Notes (iterations 11-12, hardening)

- A method is a solver script in `scripts/solvers/`. Both evaluators enumerate that directory, run every solver once per instance in a fresh process with 20 CPU seconds (solver + children, counted from `wait4` rusage; RLIMIT_CPU, 4 GB address space), and read only the `formula` string of `answer.json`. Wall time is not budgeted: a 200 s wall limit (10x the budget) only stops hung runs. Every solver is entered with the worst values (0 / 0 / 10) before it runs.
- Train: 80 instances from the paper's released suite (`data/train/`, answer fields stripped), 8 per family for all ten families, sampled uniformly over the released parameter combinations (`data/prepare_train.py`); the five formula-based families have their propositions renamed `a0..` (permutation recorded in the manifest).
- Test: 80 fresh draws (8 per family) over the same parameter combinations with unrecorded OS-random seeds (`eval/test/build_instances.py`): the dedicated instance generators for five families; for Fixed_Formulas, SingleCounter, DoubleCounter, Nim, Random_Conjuncts_from_Basis the family formula plus uniform sampling of the language and its complement (`eval/test/trace_sampler.py`, a Spot-free equivalent of the paper's sample.py). Stored only in `eval/test/instances.json`.
- Best-known sizes (`eval/test/instances.json`, `eval/train/reference_sizes.json`) = min over every valid learner separator recorded in iterations 11-12 (the generating formula counts when smaller and some learner solved the instance); where no learner solved an instance, the exhaustive-enumeration lower bound (`build_reference_sizes.py`, `scripts/hardening/lower_bounds.py`); frozen afterwards.
- Metrics: `size_efficiency` (primary), `solve_rate`, `size_ratio_geomean`, all computed by the evaluator from the parsed formula. Failures score 0 / 0 / 10.
- The hidden test keeps solver records in memory (no formulas written to disk during or after a default run) and makes its reference-size files unreadable while solvers run.
- `eval/train` and `eval/test` share no code (duplicated parser/semantics); neither imports `method/`.
